Paso 3: El Servidor procesa la Solicitud

El servidor web (como Apache o Nginx) recibe la petición, verifica si el archivo existe o ejecuta código de programación en el backend. Finalmente, genera un código de estado de respuesta para comunicarle al navegador el resultado de la operación.

Códigos de Estado Comunes

  • 200 OK: La solicitud ha tenido éxito y el recurso se envía.
  • 404 Not Found: El servidor no pudo encontrar el recurso solicitado.
  • 500 Internal Server Error: El servidor encontró una condición inesperada.

Ejemplo de Encabezado de Respuesta

Cabecera HTTP de Respuesta típica
Línea de Cabecera Significado
HTTP/1.1 200 OK Protocolo y estado exitoso.
Content-Type: text/html; charset=UTF-8 Formato de datos devuelto.
