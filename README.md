Simulador Educativo: Funcionamiento de la Web
Este proyecto es un Simulador Educativo desarrollado como parte de la actividad de aprendizaje (APE) de la Unidad 6. El objetivo principal es la modernización de un sitio web del primer bimestre, implementando un rediseño centrado en el usuario mediante el uso de un framework CSS y estándares de accesibilidad.

🛠 Framework Utilizado: Bootstrap 5
Se ha seleccionado Bootstrap 5 por ser un framework robusto y eficiente.

Ventajas:

Consistencia: Permite mantener un diseño uniforme en todos los componentes y páginas.

Responsividad: Su sistema de grillas (grid system) facilita enormemente la adaptabilidad del sitio a dispositivos móviles, tablets y escritorio sin necesidad de media queries complejas.

🚀 Características del Rediseño
Estructura Semántica: Implementación de etiquetas HTML5 (<header>, <nav>, <main>, <section>, <footer>) para mejorar la semántica y accesibilidad.

Diseño Responsivo: Adaptación completa a dispositivos móviles mediante el uso de contenedores (.container) y clases de ajuste (img-fluid, table-responsive).

Jerarquía y Legibilidad: Reorganización del contenido para asegurar un orden lógico de lectura y una navegación clara entre las 5 páginas del sitio.

Componentes Interactivos: Uso de navbar responsive, cards para paneles informativos, tablas estilizadas y botones con estados de interacción (hover/focus).

♿ Checklist de Accesibilidad Aplicada
Para cumplir con los estándares WCAG, se han verificado los siguientes puntos:

[x] Etiquetas Alt: Todas las imágenes cuentan con su atributo alt descriptivo.

[x] Contraste: Uso de paleta de colores de Bootstrap que garantiza una relación de contraste adecuada entre texto y fondo.

[x] Navegación: Estructura de encabezados (h1 a h4) en orden lógico.

[x] Responsividad: El diseño permite una lectura cómoda sin scroll horizontal en dispositivos móviles.

[x] Interactividad: Los enlaces y botones poseen estados visuales claros al recibir el foco (focus) o pasar el cursor (hover).
