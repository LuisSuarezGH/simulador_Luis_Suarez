Paso 1: El usuario ingresa una URL

Todo comienza cuando escribes una dirección (como https://www.ejemplo.com) en la barra del navegador. Este nombre amigable debe traducirse a una dirección IP numérica mediante el sistema DNS para saber exactamente a qué servidor dirigirse.

Componentes de una URL

  • Esquema: Indica el protocolo (HTTP o HTTPS).
  • Host: El nombre del dominio (servidor de destino).
  • Ruta: El recurso específico que se solicita dentro del servidor.
