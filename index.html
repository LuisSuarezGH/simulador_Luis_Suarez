Paso 1: El usuario ingresa una URL

La navegación web comienza cuando el usuario, mediante el uso de un dispositivo electrónico, ingresa una dirección de dominio en la barra de navegación. Posteriormente, la infraestructura DNS interviene para realizar una resolución de nombres, transformando el dominio legible en su correspondiente dirección IP numérica.

Componentes de una URL

  • Esquema: Indica el protocolo (HTTP o HTTPS).
  • Host: El nombre del dominio (servidor de destino).
  • Ruta: El recurso específico que se solicita dentro del servidor.
