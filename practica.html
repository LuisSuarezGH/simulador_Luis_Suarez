1. El Texto y los Párrafos

Cuando el motor del navegador lee la etiqueta <p>, procesa el texto plano y aplica los estilos tipográficos base. El texto se acomoda en bloques independientes según el flujo de lectura de arriba hacia abajo.

2. Renderizado de Imágenes

Al encontrar la etiqueta <img>, el navegador busca el archivo y reserva el espacio en píxeles configurado.

3. Construcción de Listas de Datos

  • Lectura del código: El navegador detecta la apertura del contenedor.
  • Asignación de viñetas: Se dibuja un marcador visual por cada fila encontrada.
  • Cierre del bloque: Se rompe el flujo de lista para continuar.

6. Conclusión

  1. El usuario escribe una dirección web.
  2. El sistema DNS busca la dirección IP.
  3. El navegador envía una solicitud HTTP.
  4. El servidor busca el recurso.
  5. El servidor responde con datos y código de estado.
  6. El navegador renderiza la página.
